## [Unreleased]

### Fixed (2026-10-29, the docs head-seam leg)

- The docs head had two owners: `docs/_layouts/default.html` hand-wrote canonical + the og set, and `docs/_freestruct/inject-brand.html` carried only "the layer the layout lacked". freestruct injects missing-only PER SET, so the layout's `og:title` made `hasOg` true and the engine skipped its whole og block - meaning the day an `og.image` landed in `docs/freestruct.config.yml` it would reach ZERO pages (eyestruct#23; freestruct#46; crashtest#42 is the worked example). Now there is one head owner: the layout keeps `<title>`/description/robots/icon and hands og/canonical/twitter/JSON-LD to the engine, and the template carries the engine's FULL head set. The same pass found and fixed a live bug - `site.url` carried the `/eyestruct` path AND `basePath: /eyestruct` prefixed it, so `sitemap.xml` + `feed.xml` shipped doubled URLs (`https://docs.creadev.org/eyestruct/eyestruct/...`, both 404 live); `site.url` is now origin-only, matching crashtest; `docs.yml`'s stale comment claiming a `pagesUrlFor` guard already de-duplicated this is corrected (the live sitemap proved there is no such guard). `og.type` moves to config (the layout's `article` default was lost with the hand-written block). `tests/docs-seo.test.js` runs the real pinned freestruct engine over a synthetic `_site` (no Ruby, no network) and pins both og.image states, the single-join URL shape, and the layout's source - so the seam can never quietly starve again. No counted surface moved.

### Added (2026-10-29, the unknown-tag leg)

- `scripts/check-jekyll-filters.cjs` refuses a second class of source-level Liquid that only fails at Jekyll BUILD time (eyestruct#24): an UNKNOWN tag. The `{% seo %}` trap that killed poststruct's docs deploy - a literal tag in prose, in backticks, which are markdown, not Liquid escaping - is now named in `lint:docs` with a file:line instead of in Jekyll's stack trace. A `KNOWN_TAGS` set of the Jekyll 4.x core + Liquid tags is the allowlist; `{% raw %}...{% endraw %}` regions are exempt (the body is blanked while line count is preserved, so `file:line` stays honest). The pass grew the two-arg-filter rule's own class, one line of the same contract. `tests/jekyll-filters.test.js` pins all of it: the repo's own docs pass, an unknown tag refuses by name, a raw-wrapped literal is exempt, the two-arg filter rule still refuses, and a known tag is not over-refused.

## [1.1.0] - 2026-10-28

### Added (2026-10-29, the pixel-tolerance lane)

- The pixel-tolerance lane landed as the T-T8 commit chain (eyestruct#11, R-C2): a manifest ROUTE ROW may carry `tolerance:` - `strict` (default) or ONE token naming all three bounds, `channel:<0-255>,pixels:<0-1>,bbox:<WxH>` (all-or-nothing; unknown tokens, out-of-range bounds, half-named profiles, and spaced-profile fragment keys all refuse `MANIFEST_CORRUPT` at the read). The comparison math lives in ONE pure module (`lib/tolerance.js`): a pixel is changed when any channel's abs delta exceeds the channel cap, and the slot passes when the changed-pixel fraction fits the pixels cap and the changed set's bbox span fits the bbox pair (read orientation-free, pairwise-sorted - the shape khf-wp's measured receipts produced and their excluded movers exceed). `diff` under a tolerant slot judges by profile with the measured numbers attached; `ratify` under a tolerant slot cuts canon as a differently-named pledge (pixel-eq at bounded span, not byte-eq) and receipts the profile verbatim in the row it writes - the optional flat `tolerance` ledger field, absent fields read strict, old copies readable. Gate is untouched (ledger accounting, browserless, T-T3), and the counted-change surface is zero (no verb/tool/code/env - T-T4's census holds). Carrier-first: eye-shapes carried the profile-jail cases before the lib landed (pack ledger 38 -> 42 verdicts, census pins moved same-commit), and the battery pins the pure math on synthetic plates at every bound edge (tests/tolerance.test.js) - never the CDP flake itself (T-T6). T-T7 stands as khf-wp's run-root gate: three consecutive green canon cuts on their measured profiles in the pinned environment are still theirs to produce (reported back on eyestruct#11).
