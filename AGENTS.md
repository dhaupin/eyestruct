# eyestruct - agent knowledge

Working policies (seed; the brain grows these by working):

- Receipts rule every claim: what broke, what the rule is now. No receipt, no ledger row changes.
- Process-per-look: never a resident daemon. Browserless verbs (init/manifest/ledger/gate/adopt/raster) must never require a browser.
- Canon is CI-cut. Local captures/adopts are probes and proposals; the ledger row that makes a baseline official is written by the CI lane in the pinned image.
- Failures carry named reason-codes and the 0-1-2 exit contract. Never a bare stack trace, never a guessed parse (the vant inspect receipt).
- Tests: `npm test` (node:test, behavior-only, temp dirs, no network). Docs gates: `npm run lint:docs` - the PRD lives at labs/ UNDER ITS OWN VOICE (em-dash); docs/ is hyphen-voice and must stay clean.
- Where things live: `labs/` (PRD canonical, TASKS, the eye home at `labs/.eyes/` - the CLI default now - and the receipt hall at  `labs/.eyes-receipt/`), `horcrux/` (the transfer stones),  `packs/public/` (5 adversarial packs + `packs/eye-ledger.json`; packstruct-linted; `eye-bundle` covers the vendored browser lane, `eye-adapter` carries the adapter surface's schema), `web/` + `docs/` (the rig). - The battery is `.github/workflows/test.yml` (npm test + check (opens with the check:trifecta freshness leg) + the crashtest leg + the raster:gate icon leg + the floors-node18 leg (the >=18 claim re-receipted on every push)); the registry cut lane is `publish.yml` (manual dispatch, OIDC trusted publishing, 0.x refusal at the gate, battery riding prepublishOnly); the docs lane is `docs.yml` (Jekyll + freestruct + pagefind -> Pages at docs.creadev.org/eyestruct); canon lane is `eyes-ratify.yml` (manual dispatch, the only baseline cutter). The freshness leg's history probes carry a clone-depth contract (eyestruct#6): a shallow checkout self-deepens once, a refused deepen names SHALLOW_CLONE and skips the probes - consumers never need fetch-depth 0 to get an honest verdict.
- The 1.0.0 stability law (eyestruct#10): within 1.x, no removal or semantic change on the public surfaces - the 13 COMMANDS verbs + usage flags (bin/eyestruct.js; serve + spot joined 2026-10-28 as the minor bump the law prescribes, with docs/cli.md moved in the same commit), the 29 reason codes + the 0-1-2 exit contract (lib/reasons.js; UNKNOWN_FLAG joined 2026-10-28 as the interface-honesty refusal, docs/reasons.md mirrored in the same change), the 10 TOOLS + inputSchemas (lib/mcp.js; spot joined 2026-10-28 as the same-class minor bump, docs/mcp.md in the same change), the labs/.eyes/ manifest-pin schema (pin: browser-image + renderer required, browser-exec optional; route rows need path/view/theme/ viewport, with optional slot: naming the walk candidate over the path-slug default - `candidateName` is the only reader; the shape the parser names and the contract legs jail), the ledger row schema (rows need id/ts/agent/commit/type/note, plus artifact or a non-empty artifacts wave array; paths are eyes-relative at write AND read - UNSAFE_PATH), the package exports map ( eyestruct, eyestruct/lib/index.js, eyestruct/package.json; deeper paths refuse ERR_PACKAGE_PATH_NOT_EXPORTED - the deep-require clamp), the env-var inventory (EYESTRUCT_BROWSER / BUNDLE_CACHE / AGENT / COMMIT, docs/env.md is the mirror; the contract leg derives the set from source), and the browserless --json machine-output shapes (key snapshots in tests/contract.test.js), the adapter contract (lib/index.js, eyestruct-adapter@1; docs/adapters.md is its mirror; additions are minor bumps), and the packstruct@1 grammar pin. Additions are minor bumps, always with the mirrored docs page updated in the same commit; removals and semantic changes ride 2.0 only.
- The bridge/carrier ruling (2026-10-28): adapters and connectors are STRICTLY bridges - they move calls/events/artifacts between surfaces and never define, author, or evolve schema. Anything schema-touching lands as a CARRIER pack in packs/public/ under the packstruct@1 grammar first. lib/index.js names its carrier via SCHEMA_CARRIER (packs/public/eye-adapter); a bridge that outruns its pack is refused by name in the campaign.
- The product story, three altitudes (README "The three altitudes" is the canonical statement): CI for devs/enterprise (shipping), adapters for agent platforms/cloud builders (MCP stdio is the first adapter, lib/index.js eyestruct-adapter@1 the second - platform adapters ride them; hosted-builder ones still designed), and real-time eyes inside the chat session via bridges/connectors (the designed pinnacle, NOT shipped - never claim it works today).
- The instance loop is native: `eyestruct serve [dir]` serves a baked tree with the committed _headers rules host-shaped (the ONE implementation, lib/serve-dist.js, shared with the battery leg + the chromium lane; a starter like mcp), and `eyestruct spot <url>` saves one capture to labs/.eyes-candidates/spot-*.png for the coding agent to read with its own vision. The loop: serve -> spot -> read -> act -> re-spot. Playbook: docs/playbooks/agents-vision.md.
- The count census (tests/census.test.js): count-claims on the audited docs/meta surfaces must equal the live ledgers and source tables; change a count and its claims in the same commit or CI fails the copy. Never hand-copy a number the census can derive.
- The walk-exit rule (the promotion rule, 2026-10-28): a manual walk is not done until nothing it found is uncommissioned. A probe that never got encoded is a one-mortem; the walk's exit criterion is that every finding is now permanent - a battery leg, a pack verdict row, or a named docket row - so future walks only see fresh ground. Walks DISCOVER classes; packs REMEMBER them. Worked example: the jpg content-type refusal (serve round) became the served-contract jpg leg in the same session; the serve-dist HTTP-shape probes became tests/serve-dist.test.js; the lint-packs exit-fidelity claim became its adapter-api leg.
